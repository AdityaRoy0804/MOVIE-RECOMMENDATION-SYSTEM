# 🎬 Movie Recommendation System

A personalized movie recommender web app built using **Streamlit**, powered by **collaborative filtering** via the `Surprise` library.

🚀 **Live App**: [https://adityaroy-movie-recommender.streamlit.app/](https://adityaroy-movie-recommender.streamlit.app/)  
📂 **GitHub Repository**: [MOVIE-RECOMMENDATION-SYSTEM](https://github.com/AdityaRoy0804/MOVIE-RECOMMENDATION-SYSTEM)

---

## 📌 Features

- 🔐 User Login & Registration System
- 🎥 Personalized movie recommendations
- 📊 Interactive UI using Streamlit
- 💾 Lightweight database with SQLite
- ⚙️ SVD-based Collaborative Filtering
- ☁️ Deployed on Streamlit Cloud

---

## 🧰 Tech Stack


- **Python**: Core Programming Language  
- **Streamlit**: Web App Framework  
- **scikit-surprise**: Recommendation Algorithm (SVD)  
- **pandas**: Data Manipulation  
- **SQLite**: User Data Storage  
- **joblib**: Model Serialization  

---

## 🛠️ Installation

Follow the steps below to set up and run the Movie Recommendation System locally:


### Step 1: Clone the Repository & Navigate to Project Directory
```bash
git clone https://github.com/AdityaRoy0804/MOVIE-RECOMMENDATION-SYSTEM.git
cd MOVIE-RECOMMENDATION-SYSTEM
```

### Step 2: Install Dependencies
```bash
pip install -r requirements.txt
```
### Step 3: Run the Streamlit App
```bash
streamlit run CT_TASK_4_dashboard.py
```

## 🧠 Recommendation Model
  #### 1. *Algorithm: SVD (Singular Value Decomposition)*

  #### 2. *Library: scikit-surprise*

  #### 3. *Approach: Collaborative Filtering — predicts user preferences based on similarities in rating patterns.*

---
## 💡 How It Works
🔐 User logs in or registers

📂 System checks past ratings

🎯 Recommender predicts top movies using SVD

🎞️ Recommendations are displayed on screen
